# 💳 Credit Card Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Credit Card Analytics Dashboard** developed using **Microsoft Power BI**. The dashboard is divided into two major reports:

1. **Credit Card Customer Report**
2. **Credit Card Transaction Report**

The reports provide an interactive view of revenue, transaction amount, interest earned, customer demographics, card categories, expenditure types, transaction methods, and other customer-related metrics.

The dashboard helps analyze credit card performance and understand customer and transaction patterns through interactive visualizations and filters.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall credit card revenue and transaction performance.
- Understand customer demographics and their contribution to revenue.
- Compare revenue across different card categories.
- Analyze revenue based on customer occupation, education, age, income group, and marital status.
- Analyze transaction patterns across different expenditure types.
- Compare transaction performance across quarters.
- Analyze transaction methods such as Swipe, Chip, and Online.
- Identify high-performing states based on revenue.
- Provide an interactive dashboard for business-oriented analysis.
